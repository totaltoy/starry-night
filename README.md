# 星野 · 今夜只听星光

一片会呼吸的星空。纯静态单页，无框架、无构建、无外部依赖。

## 在线访问

推送后开通 GitHub Pages，地址是：

```
https://<你的用户名>.github.io/<仓库名>/
```

## 这是什么

- **星空**：三层视差星点（按真实恒星光谱型配色）、有脊线与暗尘裂谷的银河、
  随机划过的流星与火流星
- **呼吸引导**：右侧一颗由星光汇聚成的土星。吸气时星尘聚拢变亮，屏息时维持，
  呼气时散开变暗（4-7-8 节奏）。你也可以点页面任意位置立即开始
- **交互**：移动光标会点亮附近的星并留下星光拖尾，点击散开一片星尘
- **环境音**：低频垫音 + 粉噪声空气感 + 偶发颂钵泛音，全部由 Web Audio 实时合成，
  不含任何音频文件

## 技术说明

- 单个 `index.html`，CSS 与 JS 全部内联，**断网可用**
- 星空 / 银河用 Canvas 2D 逐帧绘制，无第三方库
- 全站只用系统字体（苹方 / 苹方回退），不加载外部字体
- 尊重系统的「减弱动效」设置

## 本地查看

直接双击 `index.html` 即可，或起一个静态服务：

```bash
python3 -m http.server 8000
```

然后访问 http://127.0.0.1:8000/
